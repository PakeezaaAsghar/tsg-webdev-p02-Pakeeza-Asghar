Palmar — Coastal-Inspired Premium Dining Landing Page
 The Sky Gen | Web Development Program — Project 02 (Beginner Level)

 Business Concept Brief
Palmar is a premium, coastal-inspired restaurant specializing in fresh seafood, artisanal dishes, and vibrant tropical flavors. Designed to transport guests to a relaxed seaside paradise, the brand blends a sophisticated aesthetic with a warm, welcoming atmosphere. The target audience includes food enthusiasts, couples, and travelers seeking an exceptional, high-quality dining experience. This responsive landing page is designed to maximize table reservations, showcase seasonal chef specialties, and provide a seamless interactive experience through a responsive menu category filter, customer testimonials, and clear dining pricing options.

 Tools & Technologies Used
Frontend Structure: HTML5 (Semantic Layout)
Styling & Design System: Pure CSS3 (Custom Properties & Modern Variables Architecture)
Interactivity Engines:Vanilla JavaScript (ES6+ Native Logic)
Iconographies Suite: FontAwesome Core CDN v6.0.0
Third-Party Components: Google Maps Embed API
Asset Optimization: Unsplash Creative Commons Media

 Implemented Core Features

 Required Elements
1. **Sticky Navigation:** Follows scrolling smoothly with anchor link targeting and clean JavaScript-driven active link highlights.
2. **Asymmetric Hero Layout:** High-conversion split design presenting a clear reservation CTA and customized image masking.
3. **Services Module:** Bento Grid architecture featuring three specialized experiential focus cards complete with dynamic scale shifts and hover interactions.
4. **Three-Tier Pricing Grid:** Showcases distinct custom dinner/event package selections highlighting the recommended plan.
5. **Interactive Testimonials Slider:** Smooth, pure JavaScript client-review carousel equipped with loop boundaries and previous/next navigation buttons.
6. **FAQ Accordion Panel:** Native script-controlled accordion hosting 5 structured inquiries with custom max-height expansion rules.
7. **Contact Mapping Integration:** Fully interactive input booking form aligned with a responsive Google Maps Embed frame.
8. **Multi-Breakpoint Responsiveness:** Fluid layouts optimized across Desktop, Tablet, and Mobile phone breakpoints with a functional slider mobile hamburger menu.

Bonus Extended Features
* **Dynamic Menu Category Filter:** Native JavaScript sorting tabs that seamlessly filter menu card displays across *All, Mains, Desserts, and Drinks* without needing any external library frameworks.

Repository & Submission Layout
* `index.html` — Document markup base containing all 8 mandatory visual areas.
* `style.css` — Standard typography hierarchies, responsive grid queries, and variables layout palette.
* `script.js` — Native interaction event listeners for the accordion, navbar, filter, and testimonials slider.
* `README.md` — Project context and functional requirements checklist.
